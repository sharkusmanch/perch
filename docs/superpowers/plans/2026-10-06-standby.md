# StandBy Fork Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the Dock screensaver into a StandBy-style display: three swipeable pages, a vertical carousel of three clock faces, and a light-sensor-driven red Night Mode.

**Architecture:** Keep the View-based `DreamService`. A horizontal `ViewPager2` hosts three long-lived page objects; the Clock page hosts a vertical `ViewPager2` of custom-drawn faces. Night Mode is decided by a pure-Kotlin state machine fed by the light sensor and rendered as a colour-matrix layer on the root view.

**Tech Stack:** Kotlin 1.9.22, AGP 8.2.2, Gradle 8.5, compileSdk/targetSdk 34, minSdk 26, androidx.viewpager2 1.1.0, Glide 4.16 (existing), JUnit 4.13.2.

**Spec:** `docs/superpowers/specs/2026-10-06-standby-design.md`

**Execution:** the user chose autonomous execution in-session with subagent reviews of the changes; stop after local verification, before the phone test.

## Global Constraints

- `applicationId = "io.github.sharkusmanch.dock"`; Kotlin `namespace` stays `com.nousresearch.dock`.
- App label `Dock StandBy`; `versionName 2.0.0`, `versionCode 3`.
- Page order: Widgets (0), Photos (1), Clock (2). Default page on first run: Clock. Faces: Digital (0), Analog (1), Float (2).
- Night Mode thresholds are constants: enter `< 5 lux`, exit `> 15 lux`, dwell `5000 ms`, brightness `0.01f`.
- Nothing is published (no push, no release, no tag). Local commits on branch `standby` only.
- No new runtime permissions; no network.
- Apache 2.0 `LICENSE` and upstream credit are kept.

## Review Focus

1. Light sensor reports once and goes silent (steady dark room) → Night Mode must still switch on at the dwell deadline. Test: `NightModeDeciderTest.singleSampleThenSilenceFlipsAtDeadline`.
2. Dream starts in an already-dark room → red immediately, no 5 s of full brightness. Test: `firstSampleAppliedImmediately`.
3. Light flickers across a threshold for less than the dwell → no flip. Test: `flickerShorterThanDwellIsIgnored`.
4. Midnight / noon in 12-hour mode → shows 12, not 0. Test: `ClockMathTest.twelveHourMidnightAndNoon`.
5. A user upgrading settings left over from removed preferences / dangling `android:dependency` → settings screen must open. Check: open Settings on the emulator (Task 8).

## Interfaces (shared by all tasks)

```kotlin
// dream/faces/ClockMath.kt
object ClockMath {
    fun hourAngle(hour: Int, minute: Int, second: Int): Float      // degrees clockwise from 12
    fun minuteAngle(minute: Int, second: Int): Float
    fun secondAngle(second: Int): Float
    fun formatTime(hour24: Int, minute: Int, is24Hour: Boolean): String  // "9:41", "0:05", "12:00"
    fun msUntilNextMinute(nowMs: Long): Long                       // 1..60000
    fun msUntilNextSecond(nowMs: Long): Long                       // 1..1000
}

// dream/night/NightModeDecider.kt
class NightModeDecider(enterLux: Float = 5f, exitLux: Float = 15f, dwellMs: Long = 5000L) {
    fun onSample(lux: Float, nowMs: Long)
    fun stateAt(nowMs: Long): Boolean
    fun nextDeadlineMs(): Long?
}

// dream/night/NightTint.kt
object NightTint { fun matrix(fraction: Float): FloatArray }   // 20 values, 0 = identity, 1 = luminance→red

// dream/night/NightModeController.kt
class NightModeController(context: Context, onChange: (Boolean) -> Unit) {
    val hasSensor: Boolean
    fun start(); fun stop()
}

// dream/pages/DreamPage.kt
interface DreamPage {
    val view: View
    fun attach()            // once per dream start
    fun detach()            // once per dream stop
    fun resume()            // page selected
    fun pause()             // page deselected
    fun refresh() {}        // one-shot redraw when a swipe starts
    fun setNightMode(on: Boolean) {}
}

// dream/faces/BaseFaceView.kt
interface ClockFace { var accentColor: Int; var is24Hour: Boolean; var nightMode: Boolean; fun resume(); fun pause() }
abstract class BaseFaceView(context: Context) : View(context), ClockFace {
    protected abstract fun nextDelayMs(nowMs: Long): Long
}
```

Preference keys (default SharedPreferences): kept `app_theme`, `oled_mode`, `clock_24h`, `battery_enabled`, `slideshow_interval`, `slideshow_photo_uris`, `widget_slot_count`, `slot_size_N`; new `night_mode_enabled` (bool, default true), `face_color_digital` (`#FFFFFF`), `face_color_analog` (`#FF9F0A`), `face_color_float` (`#FF6482`), `last_page` (int, default 2), `last_face` (int, default 0).
